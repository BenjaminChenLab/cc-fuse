# cc-fuse 方向性避難閘(暫停只停 A→B + 六日 checkbox)— 規格

日期:2026-11-17。上層設計:`2026-11-15-cc-fuse-design.md`(政策 §6、預算 §7、設定 §9)。
本文件是 spec-tdd-lite(2026-11-17 session)的需求事實來源:需求原文 + 詮釋決定 + 驗收測試路徑。

## 需求原文(Benjamin,2026-11-17,逐字)

> 1. stop autopilot, 改成只停止 a to b, 不停 b to a
> 2. 加一個六日不開 a to b 的 checkbox

## 對話中已核准的設計決定(2026-11-17,非沉默詮釋)

1. **暫停語意改方向性**:暫停(autopilot off)只封鎖 A→B 方向的自動切換——
   P3(在 A、A 過熱、B 可用 → 切 B 避難)與 P6 仲裁中的「切去 B」都被擋,留守 A。
   **B→A 方向不受暫停影響**:P4(A 恢復 → 切回 A)、P5(B 燒到當日天花板 → 強制切回 A)照常運作。
2. **新設定 `noFleeOnWeekend`(預設不勾)**:勾選時,本機時間週六、週日同樣封鎖 A→B(效果同暫停,但只封鎖該方向);B→A 照常。不勾 = 現狀行為完全不變。
3. **文案**:系統匣選單與設定窗按鈕/狀態行改用「暫停自動切 B / 恢復自動切 B」「自動切 B:開/已暫停(切回 A 照常)」(Benjamin 挑選的選項)。
4. **連帶行為改變(已在對話中明列並核准)**:暫停期間 §7 每日預算結算**照跑**(舊行為暫停=整輪早退、結算凍結;新語意下 P5 需要當日天花板,結算必須活著)。資料品質閘(P2 過期/缺失/當前帳號金鑰失效)在暫停時也照常運作。
5. **擋下來的表現**:留守 A(ActionStay),理由字串含「封鎖」並寫明原因(暫停/六日);不另發新通知(P7 預警線 80% 一次性通知本來就會響)。P4/P5 切回 A 時照翻 quota-mode → RACING。
6. **手動切換(P1)與未知供應商停車(P8)行為不變**:手動永遠穿透封鎖;P8 未知供應商仍停用 A→B。

## 詮釋決定(明列,Phase 3 審計須逐一檢核)

- 「六日」= 週六與週日,以**決策當下注入的 Now(主迴圈傳入的本機時間)**的 weekday 判定;不處理假日補班/國定假日。
- 邊界:精確以日期翻轉——週五 23:59 仍放行 A→B,週六 00:00 起封鎖;週日 23:59 封鎖,週一 00:00 放行(含等號方向以 weekday 判定為準,無秒級灰區)。
- 「不停 b to a」含 P5(天花板強制切回)——它也是 B→A,照常。
- 封鎖範圍含 P6 仲裁的切 B(A 過熱、B 不可用、B 的 5h 重置較早時,舊邏輯會切進 B 等重置——那也是 A→B)。
- checkbox 放設定窗「閾值(%)」區;config 鍵 `noFleeOnWeekend`,頂層欄位(非 budget 區)。
